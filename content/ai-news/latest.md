## Models and local inference

The family spans 0.8B–12B (Qwen3.5 bases) plus the 31B, all Apache-2.0 with trained linear readouts for choice/yes-no/score decisions over text and images (up to 255 options, multiple questions per forward pass); BF16 31B needs ~62.5 GB, and a community IQ3_M GGUF (PsychoLogic, Nov 14) makes smaller cards viable. **Training-free page-sparse decode in llama.cpp: 1.72x at 128k on an RTX 5090.** A fork posted at 9:13 ET splits the KV cache into 64-token pages and lets each KV head read only the first page, newest tokens, and predicted-important pages (~21% of cache per decode step at 128k), following Quest-style selection with MOIRA-flavored statistics. Measured: Qwen3-30B-A3B Q4_K_M 46.1→79.2 tok/s (1.72x) on a 5090 with −1.0 RULER; Qwen3-8B 1.68x and Llama-3.1-8B 1.64x on a 3090; a 3B run failed multi-needle (−4.5). *Why it matters:* sparse-KV decoding that needs no retraining and no serving-stack rewrite is the cheapest path to long-context speedups on consumer cards — the 3B failure also shows where the accuracy cliff still is. (Self-published; single-source; the post carries an AI-generated-content flag.)
Source: Reddit (r/LocalLLaMA), Nov 16, 2026 09:13 ET — https://www.reddit.com/r/LocalLLaMA/comments/1xxqdil/trainingfree_pagesparse_decode_in_llamacpp/
Local inference: results are on RTX 3090/4090/5090 — directly relevant to 16 GB-class boxes, though only the small models fit comfortably.

## Agent tools

**Show HN: Coral — open-source gateway where agents write their own tools.** Posted 9:14 ET (46 points): a self-hosted, Rust, Apache-2.0 gateway between agents and the systems they touch. Agents call tools by writing short TypeScript programs, which are saved as reusable custom tools; each program runs in a V8 isolate with no network or credentials, and every tool call is checked against workspace policy before credentials attach. Team-shared tool libraries adapt to your systems; providers can use each caller's own account so teammates share tools without sharing API tokens. The team measured 29% faster and 31% cheaper agent runs on GitHub/Linear/Slack tasks with Opus 5.5. SAML/SCIM/org governance come later under an enterprise license. *Why it matters:* "code mode" + policy-gated credential brokering is consolidating into a product category — and it directly addresses the token/permissions blast-radius problem that several AI-supply-chain breaches this month have exposed.
Source: Hacker News (story 50517803), Nov 16, 2026 09:14 ET — https://news.ycombinator.com/item?id=50517803 ; repo — https://github.com/withcoral/coral

## AI security and governance

**LEAD — Google GTIG: first observed fully autonomous AI exploitation pipeline — an agent turned security patches into working exploits with no human in the loop.** Google's Q4-2026 AI Threat Tracker (published Monday, ~9:00 ET) documents an exposed staging server hosting "exploit_agent" — a Russian-language, multi-agent vulnerability-research and weaponization framework wired to multiple frontier and local models, configured for continuous differential analysis of popular web applications: diff code before/after vendor patches, find the n-day, write the exploit, and execute it automatically. The server held stolen victim data and post-compromise scripts (recon, brute-force, webshell install/removal); telemetry pointed to French media, entertainment and education targets. GTIG/Mandiant also report live intrusion use of open-source offensive frameworks beyond ARTEX — CAIRN (observed against US aerospace; an OODA-loop "blackboard" multi-agent design), PentAGI (also seen with proxy services), plus experimentation with CyberStrikeAI and HexStrike AI (MCP harness wrapping 150+ tools via 12 sub-agents) — by financially motivated actors and suspected PRC-nexus espionage groups, alongside LLMJacking resale of stolen model access through "LLM Mixer" proxy services. *Why it matters:* patch-to-exploit at machine speed collapses the n-day window that defenders rely on, and the framework names (CAIRN, PentAGI, HexStrike) are now named threat surface, echoing this month's ARTEX campaign cluster in the ledger.

**LEAD — BIS issues interim final rule on remote access to American "super intelligence" chips.** The Commerce Department's Bureau of Industry Security released the IFR Monday morning (press release "FOR IMMEDIATE RELEASE | November 16, 2026"; Bloomberg broke it at 8:55 ET). Written "by and at the direction of" Treasury and the National Security Council, the rule extends existing export controls to *remote* access, so restrictions "cannot be circumvented through remote computing arrangements involving data centers in third countries." Beyond existing license requirements, exporting/re-exporting/transferring covered advanced semiconductors to **Brazil, Indonesia, Malaysia, Singapore or Thailand** now requires licenses. CBS (updated 10:43 ET) ties the timing directly to the Jensen Huang/Megaspeed fallout — rent-Nvidia-compute-in-Southeast-Asia as the circumvention vector — while Trump, at the White House, said selling non-flagship chips "is a good thing." *Why it matters:* this is the rulemaking half of the ledger's china-compute-rush-rasa and missed:commerce-remote-access-rule threads — Chinese labs' practice of renting overseas Nvidia capacity now faces a licensing regime keyed to the five countries where that capacity was being built; for the local-inference ecosystem it further bifurcates where frontier weights get served.
