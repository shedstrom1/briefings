## Agent tools

**Anthropic rewrote its Messages API in Rust — using Claude agents to verify every difference**
Event date: November 25, 2026 (12:05 PM ET). Anthropic published a detailed engineering account of migrating the Messages API — the primary path through which customers and its own apps (Claude Code, Cowork) reach Claude — from Python to Rust. API traffic had grown roughly 1,800× from early 2024 to fall 2026. Claude wrote the first version of the core request path in about a week; the hard part was proving parity on a live, changing service. Anthropic turned the production Python API into a verifier, ran the Rust build against shadowed production traffic, and dispatched teams of Claude agents to reproduce and fix every divergence. The result: ~70% less CPU per request and ~20% lower median time-to-first token, shipped without taking the service offline.
Why it matters: It is a concrete, production-scale demonstration of the "generator–verifier gap" as an agentic workflow — humans define correctness, agents close the loop — and it delivers a real inference-efficiency win (lower CPU per request, lower TTFT) on the hottest API path at a frontier lab. The pattern is directly relevant to teams using coding agents on large, safety-critical migrations.
Source: Anthropic "Migrating our Messages API to Rust," 2026-11-25, https://www.anthropic.com/research/migrating-api-to-rust — Techmeme (river item, 12:05 PM ET), https://www.techmeme.com/river — CryptoBriefing "Anthropic moves its Messages API from Python to Rust," ~5 hours before 17:00 ET, https://cryptobriefing.com/anthropic-messages-api-python-to-rust/

**Google DeepMind ships "Mass Spec Skills" for Antigravity**
Event date: November 25, 2026 (blog dated 11/25; surfaced on Hacker News ~4:21 PM ET). DeepMind released a suite of domain skills that pair Gemini's chemical reasoning with established mass-spectrometry tools and public chemical databases. From a single plain-language prompt, the Antigravity agent chains the skills — reference-library search, formula determination, candidate retrieval, fragment simulation — and produces a proposed structure with an auditable report. Spectral searches currently annotate only ~5% of measured spectra (10% for human samples); the agent targets that "dark matter" of metabolomics. The skills are available in Antigravity today, and 10,000 scientists are being offered the highest usage tier free for six months.
Why it matters: This is agent tooling, not a new model — a packaged, auditable, multi-tool workflow that a domain expert can run without configuring each underlying tool. It shows the "skills" abstraction moving into scientific instrument workflows where precise computation (mass calcs, bond-break simulations) must be delegated to dedicated tools rather than left to the language model.
Source: Google DeepMind "From spectrum to structure: Identifying molecules with Mass Spec Skills for Google Antigravity," 2026-11-25, https://deepmind.google/blog/interpreting-mass-spectra-with-google-antigravity/ — Hacker News submission 50647716, 21:21 UTC (4:21 PM ET), https://news.ycombinator.com/item?id=50647716

## AI security and governance

**Italy and Switzerland warn of successful attacks run by autonomous AI agents**
Event date: November 25, 2026 (2:39 PM ET). Italy's CSIRT and Switzerland's National Cyber Security Center separately warned that autonomous AI agents have been used in real, successful intrusions against critical-infrastructure organizations. Both agencies named four frameworks seen in recent incidents: ARTEX AI, CyberStrikeAI, DeepSeek Harness – Red Team, and PentAGI. CSIRT Italia described large-scale campaigns where a coordinator assigned tasks to five parallel agents spanning reconnaissance through exploitation and persistence, with agents chaining low-impact flaws and writing malicious code in real time to evade endpoint defenses. The Swiss NCSC confirmed its first AI-assisted breaches across at least two sectors, said every known incident led to successful compromise, and warned that the number of publicly available attack agents has nearly doubled since October. Guidance: patch internet-facing systems within 24 hours, enforce MFA/passkeys, reduce internet-exposed systems, and monitor control-plane and outbound traffic.
Why it matters: Two national CERTs independently moving from "agentic attack risk" to confirmed successful intrusions is a threshold event for AI security. The tooling named — especially DeepSeek Harness and PentAGI — is open and cheap, which is exactly the combination that turns a novel technique into a mass campaign. For defenders, the 24-hour patch and least-privilege advice is immediately actionable.
Source: BleepingComputer "Italy and Switzerland warn of autonomous AI-driven cyberattacks," 2:39 PM ET, https://www.bleepingcomputer.com/news/security/italy-and-switzerland-warn-of-autonomous-ai-driven-cyberattacks/ — corroborating agency framing: SecurityWeek "Check Point Security Management Servers Hacked in AI-Assisted Campaign," https://www.securityweek.com/
