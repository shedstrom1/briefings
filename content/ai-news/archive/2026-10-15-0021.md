## Models and local inference

### Meta releases Muse Open, an 816-billion-parameter open-weight model for desktop agents
Event date: October 15, 2026

It is a natively multimodal mixture-of-experts — 816 billion total parameters, 42 billion active, 256 experts with eight activated per token — with a 1-million-token context window and text, image, video, and audio inputs producing text output. It is built for coding and agentic work, with a reasoning_effort setting (low, medium, high, xhigh; xhigh default). The weights are downloadable on Hugging Face, Amazon SageMaker, Google Cloud Model Garden, and Microsoft Foundry Models, and hosted inference is available via Baseten, Fireworks AI, Groq, Modal, Nebius, OpenRouter, and Together AI. Supported inference engines include SGLang, vLLM, TensorRT-LLM, Hugging Face Transformers, Apple MLX, llama.cpp, and Unsloth, with optimizations for AMD, Apple, Intel, and NVIDIA silicon; Meta ships custom Helion GPU kernels in SGLang reporting 1.03-3.95x kernel-level speedups on NVIDIA and AMD GPUs. Meta's own local reference runs the full model on two M5 Ultra Mac Studios (up to 512 GB unified memory each, 1.2 TB/s bandwidth) via MLX. The release is under the Muse Model License with limited commercial terms.

The broad engine support means local-inference tooling can absorb it quickly, and the on-device agent demos Meta showed (shipping iOS changes to Ice Cubes, driving DaVinci Resolve) point at desktop agents as the intended use.

Local inference: Yes — studio-class local only.

### NVIDIA releases Nemotron 3.5 Super VL and Bolt edge models
Event date: October 15, 2026

NVIDIA released Nemotron 3.5 Super VL, an open 120-billion-parameter mixture-of-experts vision-language model that activates 12 billion parameters per token, with a 1-million-token context window, targeting instruction following, tool use, multistep business workflows, and visual understanding. NVIDIA describes it as 5x faster than the next-best open agentic model in its class. The models ship with open weights, datasets, and training recipes, and an NVFP4 quantized checkpoint is on NVIDIA Build. vLLM published day-0 serving support on October 15, and llama.cpp v0.7.0 (same day) adds Super VL and Bolt support. Early customers customizing Super VL include Scale AI (for Skydance and EY agents), Hebbia, AI21, Alice, Mercor, Atlassian, CrowdStrike, Dassault Systèmes, Perplexity, Salesforce, and Synopsys.

Why it matters: NVIDIA is pitching "data center to desktop" agent deployment with an open model, so organizations can post-train on their own data and run on their own infrastructure.

### Black Forest Labs opens FLUX 3 Image Klein weights: 5.6 billion parameters, INT8 on 8 GB RTX
Event date: October 15, 2026

Black Forest Labs released FLUX 3 Image Klein, a 5.6-billion-parameter open-weights model for text-to-image generation, image editing, and multi-reference generation with up to ten reference images, sharing core capabilities with the full FLUX 3 Image model including native 4K output. The release includes a base checkpoint for fine-tuning and a step-distilled model for low-latency generation, with FP8, INT8, and NVFP4 builds developed with NVIDIA support under the FLUX Kommunity License (free commercial use for individuals and companies under $5 million annual revenue; paid self-hosted or API terms above that). The generator weighs 11.2 GB in BF16 and 5.6 GB in FP8, and the INT8 build runs on NVIDIA GeForce RTX GPUs with as little as 8 GB of VRAM through ComfyUI or Diffusers — 1-megapixel images in about 4.1 seconds on an RTX 5090 with the distilled model. Day-one support spans ComfyUI, Hugging Face Diffusers, TensorRT-LLM, SGLang Diffusion, and vLLM-Omni, with LoRA training via Ostris's AI Toolkit and NVIDIA NeMo AutoModel. API pricing starts at $0.009 per 1K image.

Local inference: Yes — the INT8 build targets 8 GB GeForce RTX GPUs, and day-one ComfyUI and Diffusers support means it drops into existing local workflows without a hosted round trip.

### llama.cpp ships v0.7.0 with Mixture-of-Experts host cache and LiliCorr speculative decoding
Event date: October 15, 2026, 5:13 PM UTC (1:13 PM EDT)

ggml-org released llama.cpp v0.7.0 on October 15. The headline local-inference feature is a new GPU cache for Mixture-of-Experts models kept in host memory (--moe-cache-mib), reported at up to roughly 2.2x decode speedup when experts are offloaded, now shared across multiple GPUs. The release also adds LiliCorr speculative decoding, MTP speculative decoding for GLM5-Next (which now accepts Qwen3.8 Flash Next image embeddings), and new model support including K2 Horizon, Prism Bonsai 2 27B, EmbeddingGemma-2, LiquidAI d1 and d1-omni, vLLM decision models, pplx-decider, MiniCPM-V 4.7, Nemotron Super 3.5 VL and Bolt, and maion-coder. The server gained a refactored chat session API, a new default port of 9931, and a web UI models manager; ggml moves to v0.27.0.

Local inference: Yes — this is a local-inference engine release, CUDA-capable on RTX 50-series, with the MoE cache specifically aimed at running bigger models on smaller cards via expert offloading.

Source:
* GitHub, ggml-org/llama.cpp, "Release v0.7.0," October 15, 2026, 17:13 UTC, https://github.com/ggml-org/llama.cpp/releases/tag/v0.7.0

Event date: October 15, 2026

Liquid AI released d1-ultra, a multimodal decision model that takes text, images, or both and returns calibrated probabilities for fixed yes/no, choice, and score questions in a single forward pass with zero generated output tokens — aimed at tasks like visual defect inspection and damage-claim assessment. ### Apate deploys thousands of undercover AI agents to bait scammers
Event date: October 15, 2026

Australian startup Apate is running thousands of autonomous agents that pose as victims across calls, messages, email, and web forums to engage scammers, then surface bank accounts, wallet addresses, and malicious sites for customers in telecom, banking, and government.

Why it matters: It turns proactive deception into repeatable fraud-intelligence feed data (blocklists, SIEM alerts, content takedowns) — a live example of agent fleets as a defensive product — while raising the usual privacy and regulatory questions around fabricated identities and cross-border data sharing.
