## Attacks and campaigns

### Free OpenCode coding agent ran a complete intrusion attempt against a financial firm in under six minutes
**Event date:** attempted Nov 16, 2026; report published Tue Nov 24, 2026 (Register 17:00 UTC / 12:00 EST).
Tel Aviv-based Jesta documented an attempted intrusion against a financial-services customer (unnamed) started at **4:24:57 a.m. ET on Nov 16** from an ordinary DIGI Romania business IPv6 address in Bucharest. The operator installed the open-source coding agent **OpenCode** on a Mac and pointed it at the target: the first request came from **Chrome 157**, six seconds later the same address retried claiming to be a **Pixel 10** Android phone; when the site refused the front page and the API definition, the agent asked for the API spec, hit a Jesta **decoy** endpoint that returned a readable API document, and followed a link inside it 13 seconds later. At 4:26:01 ET Jesta classified the visitor as an AI agent and shifted it into a fake environment, where the agent found a **planted key**, tested it with **curl/8.7.1**, then tried no-key and a fabricated key before giving up — **5m44s** total, no further activity since. Jesta says nothing in the traffic named which model powered the agent. Both the customer and Jesta disclosed to law enforcement. Severity: **Not specified by source** (no CVSS published).
**Why it matters:** this is the offensive-agent story shifting from bespoke frameworks (ARTEX, Cairn, CyberStrikeAI) to a **freely installable developer tool** — "the bar for doing this is now installing an app," per Jesta CTO Lior Finkelshtein. Reputation-based controls are useless here: the IP was unknown to every threat feed the victim subscribed to, and the traffic looked like a developer reading docs.
**Action (from the source):** defend by behavior, not blocklists — the tells were following a link that exists only inside an API doc, cycling desktop UA → fake mobile UA → curl from one address within minutes, and testing multiple keys (including a made-up one) in seconds.
Sources: *An AI coding agent, a browser, and a Mac tool found a financial firm's access key in under 6 minutes*, The Register, Nov 24 2026 17:00 UTC (12:00 EST) — https://www.theregister.com/security/2026/11/24/an-ai-coding-agent-a-browser-and-a-mac-tool-found-a-financial-firms-access-key-in-under-6-minutes/5311922 (Register exclusive; second independent outlet does not exist — syndicated summaries such as aigovernance.com's reproduce it without new material).

### Europol-led operation disrupts 57 illegal IPTV services, traces €26M in crypto
**Event date:** Europol press release Tue Nov 24, 2026 (BleepingComputer 10:10 EST).
Authorities from **11 countries** disrupted **57 illegal IPTV services** operating **321 websites** with combined traffic over **7.3 million visits a year**, tracing **more than €26 million in cryptocurrency transactions** with analysis continuing. Europol, EUIPO's IPC3, INTERPOL and the AAPA trade association worked with crypto-industry analysts from **Binance, Coinbase and Chainalysis** to link services, wallets and the individuals controlling them; AAPA puts legitimate-provider losses at ~€4.83bn/yr across ~60M European users of illegal platforms. Follows Operation KRATOS 2 (June: 27,000 URLs, 9 crime groups, 29 arrests) and Operation Switch Off (January).
**Why it matters:** the crypto-tracing tradecraft on display (wallet→controller attribution by exchange analytics teams) is the same playbook now applied to ransomware and infostealer proceeds, and these service operators are a recurring source of monetized access and malware distribution into consumer networks.

## Defensive tools and advisories

### Elastic Security 9.6: AlertZero agentic SOC workers, Linux ransomware protection, 143 AI/LLM detection rules
**Event date:** published Tue Nov 24, 2026 (Elastic Security Labs release post early Nov 24; Help Net Security coverage 07:27 EST — the vendor post appeared a few hours before the window opened).
Three pieces matter operationally. **AlertZero** (technical preview, Cloud Serverless) deploys six **Workers** across four "Watches" — triage, threat hunting, detection engineering, forensics — each running on a schedule or on events such as new alerts and submitting a proposed action (close a false positive, isolate a host) with evidence attached. Teams pick autonomy per Worker: **Manual** (analyst approves), **Assisted** (worker investigates rules/coverage gaps independently, changes still approved), **Supervised** (selected actions run first, reviewed after); approved actions execute **with the approving analyst's privileges** and are recorded as their decision. Model selection spans Efficient/Balanced/Frontier tiers including open-weight and self-hosted options. Elastic Defend extends behavior-based **ransomware protection to Linux** (Prevent mode blocks in-flight) and adds **custom YARA scanning of process memory** producing "Memory Threat – Detected" alerts, both GA in 9.6, plus termination of persistence attempts launched by coding agents on macOS/Windows. **Entity Analytics** is GA with risk tiles and an AI brief naming up to three entities to investigate first, and new resolution rules for Windows/CrowdStrike SIDs, Entra GUIDs, M365 UPNs and case-insensitive email. The release also adds **143 AI-security SIEM rules** (hijacked coding agents, malicious MCP servers, credentials pasted into prompts, jailbreaks, stolen API keys) mapped to MITRE ATLAS/ATT&CK, citing the August 2025 malicious Nx build tool that invoked installed AI coding tools and a Postmark-impersonating npm MCP package that copied outgoing email; a Security-for-AI integration package adds four in-cluster small models scoring prompts/responses.
**Why it matters:** agentic triage is arriving as a shipped SOC control with explicit, auditable autonomy levels — and the new rule corpus is the clearest vendor codification yet of the AI-agent threats (MCP server abuse, prompt-pasted credentials) this briefing has tracked since September.
**Action:** most 9.6 capabilities are in Cloud Serverless now; Elastic Defend's Linux ransomware/YARA features and Elastic Cloud Hosted / Self-Managed availability are expected **early December** with an Enterprise subscription (or trial).
Sources: *Elastic puts AI agents to work on the SOC alert backlog*, Help Net Security, Nov 24 2026 12:27 UTC (07:27 EST) — https://www.helpnetsecurity.com/2026/11/24/elastic-security-9-6-features/ ; *Elastic Security 9.6: AlertZero, AI rules, Linux ransomware*, Elastic Security Labs release post, Nov 24 2026 — https://www.elastic.co/security-labs/blog/elastic-security-9-6-release-highlights
