## Vulnerabilities and patches

### CISA adds four exploited flaws to KEV catalog (Oct 14)
CISA added four vulnerabilities to its Known Exploited Vulnerabilities catalog on October 14, 2026, citing evidence of active exploitation: CVE-2026-0322 (Palo Alto Networks PAN-OS code injection), CVE-2026-76519 (Cisco Secure Email Gateway relative path traversal), CVE-2026-105133 (Ahsay AhsayCBS improper authentication), and CVE-2026-105134 (Ahsay AhsayCBS command injection). Under Binding Operational Directive 26-04, federal civilian agencies must prioritize rapid remediation of KEV-listed flaws on publicly exposed assets; CISA encourages all organizations to adopt the same risk-based prioritization. The PAN-OS flaw (CVE-2026-0322) is rated CVSS 8.6/HIGH by the vendor and allows an authenticated attacker with network access to the management interface to execute arbitrary code with root privileges; Palo Alto observed "very limited exploitation" and provided no workaround, only version upgrades. The Cisco flaw (CVE-2026-76519) is rated CVSS 9.8 and is covered below under active attacks. Severity for the two AhsayCBS flaws is not specified by the CISA alert.

Why it matters: A KEV listing means attackers are using these flaws now, not just that they exist in theory. The PAN-OS and Cisco flaws both affect network-edge and remote-access infrastructure that sits directly on the internet, so they are high-priority patch targets.

Action: Patch affected PAN-OS and Cisco Secure Email Gateway appliances immediately; federal agencies have a CISA directive deadline of Oct 17 for the PAN-OS flaw. Restrict management-interface access to trusted internal IPs where an upgrade cannot be applied right away.

### Palo Alto PAN-OS CVE-2026-0322 exploited in the wild (Oct 14)
Palo Alto Networks published an advisory on October 14, 2026 for CVE-2026-0322, a code-injection vulnerability in the PAN-OS management interface (affecting PA-Series, VM-Series, and Panorama; Cloud NGFW and Prisma Access not impacted). The vendor rates it CVSS 8.6 (CVSS:4.0 vector AV:N/AC:L/AT:N/PR:H/UI:N), HIGH severity, exploit maturity "ATTACKED," and states "very limited exploitation has been observed." Attacker IPs associated with exploit attempts: 66.42.72.14, 208.83.239.114, 149.248.47.234. There is no workaround; the fix is a version upgrade (e.g., PAN-OS 12.2.4+, 12.1.10-h2+, 11.2.16, 11.1.16-h3, 10.2.18-h12 depending on train). Threat Prevention subscribers get limited coverage via Threat IDs 510046 and 510047, which require SSL decryption and traffic routed through a data-plane interface.

Why it matters: An authenticated RCE as root on a firewall management interface is a severe foothold, and because the management interface is often exposed for remote administration, the exposure surface is real even though authentication is required. "Very limited exploitation" confirms this is not theoretical.

Action: Upgrade to the fixed PAN-OS build for your train; restrict management-interface access to trusted jump-box IPs; enable Threat IDs 510046/510047 with SSL decryption as interim detection.

## Attacks and campaigns

### Cisco Secure Email Gateway CVE-2026-76519 under active attack (Oct 14)
Cisco disclosed on Wednesday, October 14, 2026 that attackers are exploiting CVE-2026-76519 (CVSS 9.8, Critical) in Cisco Secure Email Gateway appliances. The flaw lets a sender with no login write files to the appliance OS and, if chained, run commands as root. Exploitation requires the File Reputation service (part of Advanced Malware Protection) to be enabled on a mail policy AND the Content Scanner Tools package to be older than version 25.3.0.5525. Cisco found the flaw in its own internal scanning and became aware of the attacks in October; it does not disclose how many devices were hit, who is behind them, or whether root was obtained. Fixed scanner version 25.3.0.5525+ installs without a software upgrade or restart; full AsyncOS fixes are in 15.5.5-014 and 16.5.0-780. Cisco recommends running `grep "System Security" system_logs` to check for compromise indicators, and rebuilding (not merely upgrading) any compromised virtual appliance, since upgrading destroys forensic logs. This is the second Secure Email Gateway flaw Cisco has confirmed under attack in a month (after CVE-2026-76461, a SQL injection, on Sept 14) and the third root-level flaw confirmed exploited since December (UAT-9686 / CVE-2025-20393).

Why it matters: Email gateways are high-value, internet-facing assets; a no-login file-write leading to root command execution is a serious intrusion vector, and Cisco's anti-forensics warning (root attackers can hide logs) means compromise may be under-detected.

Action: Confirm Content Scanner Tools is version 25.3.0.5525 or later via `contentscannerstatus`; run the scanner update or enable automatic updates; migrate AsyncOS 16.0 gateways to a fixed release; run the compromise-check grep on every cluster member; contact Cisco TAC and rebuild any compromised virtual appliance with new credentials.

## Defensive tools and advisories

### CISA releases six ICS advisories, led by Eclipse Milo OPC UA flaws (Oct 15)
On October 15, 2026 CISA published six industrial control systems advisories. The headline item is ICSA-26-288-01 covering Eclipse Foundation Eclipse Milo (OPC UA stack, versions 0.6.0–1.1.4 affected), with six vulnerabilities: incorrect authorization, missing authorization, missing release of memory/resource, observable response discrepancy, and others. Successful exploitation could let an attacker delete protected data, recover user credentials and impersonate legitimate users, or crash the server. The most severe single issue, CVE-2026-60007 (padding oracle on username-token authentication), scores CVSS 3.1 7.4/HIGH and CVSS 4.0 9.1/CRITICAL; CVE-2026-58080 (missing authorization) scores CVSS 4.0 8.8/HIGH. The vendor fix is Eclipse Milo 1.1.5; users on the 0.6.x line must migrate to 1.1.5 since no 0.6.x fix exists. The other five Oct 15 advisories cover CISA Malcolm (ICSA-26-280-01), Guangzhou Juan IoT EseeCloud (ICSA-26-288-02), J4Care dcm4che (ICSMA-26-288-02), and Thermo Fisher Torrent Suite Software (ICSMA-26-288-01). Severity for the non-Milo advisories is not specified by the index listing.

Why it matters: OPC UA is widely deployed in chemical, critical manufacturing, energy, and water/wastewater ICS environments; authentication-bypass and credential-recovery flaws in an OPC UA stack can give an unauthenticated network attacker a foothold in operational technology.

Action: Upgrade Eclipse Milo to 1.1.5 (migrate from 0.6.x); minimize internet exposure of control-system devices and place them behind firewalls; review the other five advisories (ICSA-26-280-01, ICSA-26-288-02, ICSMA-26-288-01, ICSMA-26-288-02) for applicable ICS/OT and medical-device assets.
